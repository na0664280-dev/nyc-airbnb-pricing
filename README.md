# NYC Airbnb Pricing

## المشكلة
مالك شقة جديد على منصة تأجير في نيويورك ما يعرف كم يسعّر الليلة: لو غلّى ما أحد يحجز، ولو رخّص يخسر. المنصة فيها ~49 ألف إعلان وسعر الليلة من 10 إلى 10,000 دولار.

## سؤال العميل
- وش اللي يرفع سعر الليلة أو ينزّله؟
- كم السعر المناسب لشقة جديدة؟

## الداتا
New York City Airbnb Open Data (ملف AB_NYC_2019.csv): 48,895 إعلان و 16 عمود. الـ Target هو price.

## رابط التطبيق
https://nyc-airbnb-2xyu54xympzwavyhxthvpz.streamlit.app/

## التنظيف
- الداتا الأصلية 48,895 إعلان، حذفنا 264 صف، والمتبقي 48,631
- حذفنا أسعار صفر (11 صف)
- حذفنا أسعار فوق 1000 دولار (239 صف) لأنها قيم متطرفة
- حذفنا minimum_nights فوق 365 (14 صف)
- عبّينا reviews_per_month الناقصة بصفر، وأضفنا has_reviews
- أضفنا is_unavailable للإعلانات اللي availability_365 فيها صفر
- حذفنا id و host_id لأنها معرّفات

## أهم الاكتشافات
- متوسط السعر 141 دولار والوسيط 105
- أقوى عامل مرتبط بالسعر: نوع الغرفة "بيت كامل" (0.47)، ثم longitude (-0.26)

## المنتج
تطبيق Streamlit فيه 3 تبويبات: نظرة عامة، الاكتشافات، المنتج (توقع السعر حسب المنطقة ونوع الغرفة).

## طريقة التشغيل
pip install -r requirements.txt
